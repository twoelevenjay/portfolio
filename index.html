Electron panel platform

I replaced the local-server workaround vendors used to run convention panels with a code-signed, notarized Electron app for Apple Silicon, Intel Mac and Windows. Drop a build zip onto it and it relaunches as that panel, and several panels can run at once to mirror a booth's layout.

The runtime ships as an internal npm package that a React and webpack environment imports, so one backend serves web staging and the desktop build. I built it on my own time, and the team adopted it as the standard delivery format.

Built at work, so there is no public link.

Accessibility

I use the semantically correct element every time. A button is a button and a link is a link, never a div standing in for either, because the div needs a pile of extra work to catch up. Since I started working that way, the accessibility reports on my projects have gotten shorter every cycle.

I audit regulated pharma staging sites against WCAG 2.x and consult other teams on reflow, focus order, heading hierarchy, ARIA semantics and screen-reader behavior. This page follows the same rule and is checked with axe.
